Patch script reference — the little language ▶

Line numbers always refer to the numbering of the file you pasted into panel 1 (use "Copy with line numbers" so Claude sees the same numbers you do). Commands are plain text — no code fences needed. Blank lines and lines starting with # are ignored.

REPLACE line
REPLACE 12
>>>
  <h1>New Title</h1>
<<<
Replaces a single line, or a range with REPLACE 12-15, with the content in the block.
INSERT_AFTER / INSERT_BEFORE line
INSERT_AFTER 30
>>>
<script src="app.js"></script>
<<<
Inserts new content right after (or before) the given line, without touching anything else.
DELETE line
DELETE 40
DELETE 40-45
Deletes a single line or a range. No block needed.
FIND / REPLACE_WITH
FIND
>>>
color: red;
<<<
REPLACE_WITH
>>>
color: #e8a33d;
<<<
Text-based, not line-based — replaces the first exact match anywhere in the file. Good when a snippet moved or the exact line number is uncertain.
PREPEND / APPEND
APPEND
>>>
<!-- end of file -->
<<<
Adds content to the very start or very end of the file.

Order of operations: line-based commands (REPLACE / INSERT / DELETE) are applied first, from the bottom of the file upward, so earlier line numbers stay valid even as later ones shift. Then FIND / REPLACE_WITH runs on the result, then PREPEND / APPEND. Keep multiple line-based edits to non-overlapping ranges in one patch.

If you get confusing "unrecognized line" errors on a patch that looks correct, the pasted text likely picked up invisible characters (non-breaking spaces, zero-width spaces, or leftover text from a previous attempt still sitting in the box). Patchbay now auto-cleans common invisible characters before parsing and will tell you if it had to. Use Clear on panel 2 before pasting a new patch to be safe.
